## 11. 边界与错误处理

### 11.1 全局错误处理架构

| 层级 | 机制 | 说明 |
|------|------|------|
| Middleware | 异常过滤器 / error handler | |
| Service | 业务异常抛出 | |
| 日志 | 错误日志 + 上下文（requestId、userId） | |

### 11.2 错误码定义

<!-- 与 design.md 中错误码保持一致，此处补充 Backend 端内部实现细节 -->

| 业务错误码 | HTTP 状态码 | 说明 | 响应示例 |
|-----------|------------|------|---------|
| `INVALID_PARAMS` | 400 | 参数校验失败 | `{ "code": 400, "message": "..." }` |
| `UNAUTHORIZED` | 401 | 未登录 | |
| `FORBIDDEN` | 403 | 权限不足 | |
| `NOT_FOUND` | 404 | 资源不存在 | |
| `CONFLICT` | 409 | 资源冲突 | |
| `RATE_LIMITED` | 429 | 请求过于频繁 | |
| `INTERNAL_ERROR` | 500 | 服务内部错误 | |

### 11.3 边界场景

| 场景 | 触发条件 | API 行为 | 说明 |
|------|---------|---------|------|
| 空参数/缺参数 | 必填字段为空 | 返回 400 + 字段级错误 | |
| 参数边界值 | 超长文本、特殊字符 | 校验失败返回 400 | |
| 数据不存在 | 查询不存在的资源 | 返回 404 | |
| 重复提交 | 短时间内相同请求 | 幂等处理 / 返回 409 | |
| 并发冲突 | 同一资源同时修改 | 乐观锁 / 返回 409 | |
| 限流触发 | 超过频率限制 | 返回 429 + Retry-After | |
| 服务降级 | 依赖服务不可用 | 返回降级数据 / 503 | |
| SQL 注入/XSS | 恶意输入 | 参数化查询 / 转义 | |
