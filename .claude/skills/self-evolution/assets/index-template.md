# 进化素材索引

| 日期 | 会话 | 类型 | 严重程度 | 改进目标 | 状态 |
|------|------|------|---------|---------|------|
| YYYY-MM-DD | <session-name> | skill-design / skill-missing / claude-md / memory-gap / process-bottleneck / rework / memory-lookup / tool-experience / coordination / other | blocker / repetitive / friction / observation | <目标文件路径，如 `.claude/skills/feature-workflow/references/coding.md`> | 待进化 / 已进化 / 已驳回 |

---

## 字段说明

| 字段 | 说明 |
|------|------|
| **日期** | 记录日期 |
| **会话** | 会话名称（`docs/evolution/<date>-<name>/` 中的 name） |
| **类型** | 记录类型，共 10 种 |
| **严重程度** | blocker / repetitive / friction / observation |
| **改进目标** | 应该改的具体文件路径（项目相对路径） |
| **状态** | `待进化`=尚未处理 / `已进化`=已通过进化流程处理 / `已驳回`=用户决定不处理 |
