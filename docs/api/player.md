# 播放器 API

## 概述

播放器相关接口用于控制短剧视频的播放与停止。

- 所有接口均遵循 RESTful 风格。
- 请求与响应格式均为 JSON。
- 参数校验使用 Zod。

## 接口列表

### POST /api/player/start

启动播放。

**请求**

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 待定 | - | - | 请求参数由业务需求进一步定义 |

**响应**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 待定 | - | 响应结构由业务需求进一步定义 |

### POST /api/player/stop

停止播放。

**请求**

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 待定 | - | - | 请求参数由业务需求进一步定义 |

**响应**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 待定 | - | 响应结构由业务需求进一步定义 |
