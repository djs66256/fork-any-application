# 采集计划 — mall/product-card

- **采集日期**：2026-07-24
- **采集目标**：采集红果底部“商城”Tab 首屏代表商品卡片的点击承接与返回上下文，确认其是否触发商品详情、直播详情或登录拦截。
- **入口路径**：`mall/product-card/`
- **采集环境**：mobile / 红果 7.2.4.32 / Android 匿名态

## 操作步骤

- [x] 步骤 1：冷启动进入首页，切换到底部“商城”Tab，记录首屏页面。
  - 观察：成功进入“商城”Tab，首屏顶部为搜索框与购物车，下方依次为“我的订单 / 卡券红包 / 我的钱包 / 短剧同款 / 国家补贴”快捷入口、横幅和双列商品卡片流。
- [x] 步骤 2：点击首屏右上区域的代表商品卡片，记录目标页。
  - 观察：未进入商品详情或直播详情，而是在商城页上覆盖一个底部登录拦截弹层，标题为“完成抖音登录抢购超值好物”，包含手机号输入框、验证码按钮、协议勾选与抖音登录按钮。
- [x] 步骤 3：从目标页执行返回，记录返回后的商城上下文。
  - 观察：返回后登录弹层关闭，重新回到“商城”Tab 首屏；底部“商城”仍保持选中状态，双列商品卡片流继续可见。
