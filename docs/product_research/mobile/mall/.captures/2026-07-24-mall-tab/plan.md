# 采集计划 — mall

- **采集日期**：2026-07-24
- **采集目标**：采集红果底部“商城”Tab 首屏，确认其页面结构、核心商品分发模块与代表性可下钻入口。
- **入口路径**：`mall/`
- **采集环境**：mobile / 红果 7.2.4.32 / Android 匿名态

## 操作步骤

- [x] 步骤 1：冷启动进入首页，切换到“商城”Tab，记录首屏页面。
  - 观察：成功进入“商城”Tab，顶部为搜索框与购物车，下方依次可见“我的订单 / 卡券红包 / 我的钱包 / 短剧同款 / 国家补贴”快捷入口、活动横幅和双列商品卡片流。
- [x] 步骤 2：选择一个代表性入口点击，记录目标页。
  - 观察：点击首屏代表商品卡后，没有进入商品详情页，而是在商城页上弹出“完成抖音登录抢购超值好物”的登录拦截弹层，包含手机号输入、验证码、协议勾选与抖音登录按钮。
- [x] 步骤 3：执行返回，记录返回后的商城上下文。
  - 观察：返回后关闭登录弹层，重新落回“商城”Tab 首屏；底部“商城”保持选中，商品双列流继续可见。
