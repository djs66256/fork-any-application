# 分析记录 — theater/first-card

## 页面判定

- `theater/first-card` 代表路径来自底部“剧场”Tab 首屏左上第一张内容卡片，标题为“咱家剑宗团宠小师妹”。
- 点击后直接进入竖屏剧集播放承接页，而不是详情页、列表页或登录拦截页。
- 目标页顶部显示“第1集”，说明剧场首屏卡片默认承接到具体剧集播放，而非先进入作品详情。

## 首屏结构判断

- 剧场 Tab 首屏由三层结构组成：
  1. 顶部搜索框与频道横向分栏（找剧 / 真人剧 / 漫剧 / 电影 / 听书 / 小说 / 漫画 / 大视听）。
  2. 首屏快捷能力区（筛选 / 排行榜 / 新剧 / 预约）。
  3. 双列内容卡片流，卡片包含封面、热度、标题及榜单/题材标签。
- 当前默认子频道为“找剧”，说明 theater 入口不是单一榜单页，而是带频道切换能力的综合内容分发页。

## 代表路径价值

- 第一张内容卡能够代表剧场首屏标准卡片的“内容分发 → 播放承接”链路。
- 该路径证明 theater 的核心业务不是先做二次详情承接，而是尽量缩短到播放消费的路径。 `[推断]`
- 返回后重新落回剧场首屏，说明该播放链路与底部 Tab 的频道上下文强绑定，而不是独立沉浸式链路。`[推断]`

## 与已有播放页路径的关系

### 相同点
- 与 `homepage-feed/full-watch/`、`homepage-feed/menu-panel/recently-viewed/first-card/` 一样，最终都进入竖屏播放器语境。
- 都能看到顶部返回、当前集数、播放操作，以及底部选集栏。

### 不同点
- `homepage-feed/full-watch/` 的入口语义是首页 Feed 内容转化。
- `homepage-feed/menu-panel/recently-viewed/first-card/` 的入口语义是从菜单抽屉恢复续播。
- `theater/first-card/` 的入口语义则是剧场频道内的内容发现与分发，首屏本身承载“找剧”和频道切换能力。
- 返回上下文也不同：本路径返回后留在“剧场”Tab 首屏，而不是首页 Feed 或菜单抽屉。

## 去重结论

- **应保留 `theater/first-card/` 作为 theater 下的代表性子路径。**
- 原因：虽然目标页与其他入口同样进入播放器，但 theater 首屏的入口语义、上游页面结构、返回上下文都不同，不能并入已有播放页路径。
- **不继续逐一拆分 theater 首屏其他首屏卡片**，因为当前可见卡片在 UI 结构与点击后承接模式上同构，暂由 `first-card` 代表。

## 新增路径判断

- 当前首屏暴露了四个快捷入口：`筛选`、`排行榜`、`新剧`、`预约`。
- 其中：
  - `排行榜` 与首页搜索页中的 ranking 入口可能存在业务语义接近，但来源不同、是否同构尚未验证。
  - `筛选` 是 theater 首屏特有的前置能力形态，潜在属于非同构入口。
  - `预约` 可能连接到独立预约管理或预约榜单语境，潜在也属于非同构入口。
- 因本轮只验证代表性内容卡片，不在本轮直接新增子路径；建议下一轮优先从 `mall/` 或 `earn-center/` 入口继续，待入口级任务完成后，再回头补 theater 内的非同构快捷入口。
