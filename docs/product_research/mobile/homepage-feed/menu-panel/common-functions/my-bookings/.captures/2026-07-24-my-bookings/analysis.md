# 分析记录 — homepage-feed/menu-panel/common-functions/my-bookings

## 页面判定

- `my-bookings` 是菜单抽屉“常用功能”中的代表性工具入口，对应列表项文案为“我的预约”。
- 点击后进入的是独立内容管理页，而不是抽屉内展开、播放页或登录承接页。
- 当前样本页面为空态，说明匿名态下至少可以浏览预约管理页骨架。

## 页面结构

从截图可见，该页面由三层信息组成：

1. **顶部导航区**：左上返回，居中显示 `新剧预约 | 我的预约`，右上为 `编辑`。
2. **状态筛选区**：`已上线:0`、`待上线:0` 两个切换标签，用于区分预约条目的上线状态。
3. **空态内容区**：插画 + `暂无预约内容` 文案，表明当前账号或匿名态下没有预约记录。

## 与 my-downloads 的关系

- `my-downloads` 与 `my-bookings` 同处“常用功能”模块，交互入口样式完全一致，均为“左图标 + 文案 + 右箭头”的列表项。
- 现有证据显示 `my-bookings` 进入的是一个标准内容管理页；`my-downloads` 高概率也会进入同类管理页，只是管理对象由预约记录切换为下载记录。
- 因此继续沿用代表 case 去重策略：**保留 `my-bookings` 作为 common-functions 的代表性下钻路径，不再并行拆分 `my-downloads`。**

## 与其他 menu-panel 子路径的差异

- 不同于 `login-cta` 与 `game-center/more-entry` 的登录拦截链路，`my-bookings` 当前样本没有先进入统一登录页。
- 不同于 `recently-viewed/first-card` 的播放承接页，`my-bookings` 承接的是工具型管理页面。
- 返回后重新落回菜单抽屉，说明它与抽屉上下文也存在强绑定关系。

## 关键观察

1. 入口 XML 明确显示“常用功能”模块下两个可点击列表项：`我的预约`、`我的下载`。
2. 目标页截图中 `已上线:0`、`待上线:0` 与 `暂无预约内容` 共同说明该页面聚焦预约内容管理，而非内容发现。
3. 页面右上角 `编辑` 暗示当存在预约记录时，页面支持批量管理或状态调整。 `[推断]`
4. 返回截图显示抽屉仍保持打开，用户可继续浏览菜单内其它入口。

## 新增路径判断

- 本轮不新增 `my-downloads/`：其与 `my-bookings/` 在入口样式和工具页定位上同构，按用户要求由代表 case 覆盖。
- 当前样本未暴露新的非同构下游路径；页面虽有 `编辑`、状态标签等操作，但在空态下未形成新的已确认子页面。
