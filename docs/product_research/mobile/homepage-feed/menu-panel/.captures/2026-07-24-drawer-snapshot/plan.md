## 操作序列

### 步骤 1：从首页打开菜单抽屉

- **操作**：点击首页左上角菜单按钮，拉起侧边抽屉
- **命令**：`adb shell input tap 72 116 && sleep 2`
- **截图**：保存为 `assets/2026-07-24-step-01-menu-panel.png`
- **观察要点**：登录 CTA、最近在看、游戏中心与常用功能模块

*采集阶段回填：*
- **观察**：菜单以左侧抽屉形式展开。顶部为“登录看完整信息 / 立即登录”，中部是“最近在看”续播卡片，下方是“游戏中心”和“常用功能”，常用功能包含“我的预约”“我的下载”。右侧仍保留首页背景，证明这是侧滑抽屉结构。
- **截图文件**：`assets/2026-07-24-step-01-menu-panel.png`
