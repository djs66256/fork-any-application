## 功能概览

live-action-tab 是红果推荐榜顶部的内容类型标签之一，用于把推荐榜切换到真人演员出演的短剧内容池。相较默认“全部”态，它保留推荐榜的排序逻辑，但将榜单标题、条目题材与演员信息聚焦到真人剧语义。

## Use Cases

### UC-1：用户在推荐榜切换到真人剧内容池

![真人剧推荐榜](.captures/2026-07-24-live-action-tab/assets/2026-07-24-step-02-live-action-tab.png)
*图：推荐榜切换到真人剧 Tab | 采集于 2026-07-24*

- **场景**：用户认可推荐排序逻辑，但希望只浏览真人演员出演的短剧。
- **操作**：点击顶部“真人剧”Tab。
- **响应**：系统高亮“真人剧”，标题切换为《真人剧推荐榜》，并把榜单内容替换为更偏爱情、家庭、成长、都市关系等真人剧题材。
- **转场**：同页内内容类型切换。

### UC-2：用户从真人剧推荐榜返回搜索页

![返回搜索页](.captures/2026-07-24-live-action-tab/assets/2026-07-24-step-03-back-context.png)
*图：从真人剧推荐榜返回搜索页 | 采集于 2026-07-24*

- **场景**：用户浏览完真人剧推荐内容后，想回搜索页继续探索。
- **操作**：点击返回。
- **响应**：系统直接返回搜索承接页，而不是停留在推荐榜默认态。
- **转场**：整页返回搜索页。

### 内容策略

真人剧内容池保留推荐榜“个人兴趣排序”的语义，但将内容组织集中到真人演员短剧。条目更强调演员名、评分、新剧标识与都市情感/成长关系题材，体现出平台按内容形态再做一次推荐榜细分。 `[推断]`

## 关键发现

- **真人剧 Tab 是推荐榜内的内容池切换**，不是新页面跳转。
- **榜单标题随类型切换**：从《红果推荐榜》变成《真人剧推荐榜》。 `[推断]`
- **条目更强调真人演员与现实题材**：爱情、家庭、成长、都市关系等主题更集中。 `[推断]`
- **返回直接回搜索页**：真人剧推荐榜仍属于搜索体系下排行承接层的一部分。
