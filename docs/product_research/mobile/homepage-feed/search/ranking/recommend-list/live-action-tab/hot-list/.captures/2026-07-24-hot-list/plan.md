## 操作序列

### 步骤 1：在真人剧内容池切换到“热播榜”

- **操作**：进入推荐榜“真人剧”内容池后，点击二级标签“热播榜”
- **命令**：`adb shell input tap 355 587 && sleep 2`
- **截图**：保存为 `assets/2026-07-24-step-01-hot-list.png`
- **观察要点**：确认标题、说明文案、主指标和列表内容是否切换为热播榜语义

*采集阶段回填：*
- **观察**：点击“热播榜”后，页面标题切换为《红果热播榜》，说明文案变为“基于红果内观看/互动等综合热度排序”，二级标签高亮从“推荐榜”切换为“热播榜”。列表右侧主指标统一变为“xx万热度”，前几名内容横跨萌宝、家庭、玄幻、爱情、剧情等题材，说明当前状态已经从个性化推荐切回平台综合热度排序。
- **截图文件**：`assets/2026-07-24-step-01-hot-list.png`

### 步骤 2：确认返回落点

- **操作**：从真人剧内容池下的热播榜状态执行返回
- **命令**：`adb shell input keyevent KEYCODE_BACK && sleep 2`
- **截图**：保存为 `assets/2026-07-24-step-02-back-context.png`
- **观察要点**：确认返回是回到真人剧推荐榜，还是直接退出整个排行承接层

*采集阶段回填：*
- **观察**：从热播榜状态返回后，页面直接回到搜索承接页，而不是回到真人剧推荐榜或推荐榜默认态。这说明“热播榜”切换仍属于排行承接层内部状态，不形成单独回退层级。
- **截图文件**：`assets/2026-07-24-step-02-back-context.png`
