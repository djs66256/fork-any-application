## 操作序列

### 步骤 1：从首页进入搜索页

- **操作**：点击首页右上搜索图标，进入搜索承接页
- **命令**：`adb shell input tap 1000 110 && sleep 2`
- **截图**：保存为 `assets/2026-07-24-step-01-search-entry.png`
- **观察要点**：搜索框、快捷入口、搜索历史、猜你想搜与热搜榜结构

*采集阶段回填：*
- **观察**：搜索页顶部包含返回、搜索框和“搜索”按钮；下方有“识剧 / 排行 / 上新 / 演员 / 分类”快捷入口。中部展示搜索历史与猜你想搜，底部展示热搜榜内容。搜索框保留历史搜索词，页面还会叠加系统截图搜索浮层与悬浮工具提示。
- **截图文件**：`assets/2026-07-24-step-01-search-entry.png`

### 步骤 2：记录搜索页层级信息

- **操作**：导出 UI XML，确认搜索页结构和文案
- **命令**：`adb shell uiautomator dump /sdcard/step-01-search-entry.xml`
- **截图**：保存为 `assets/2026-07-24-step-01-search-entry.xml`
- **观察要点**：确认搜索框 hint、快捷入口、历史词与热搜榜模块

*采集阶段回填：*
- **观察**：XML 可观测到搜索框、快捷入口、搜索历史词（如“都市日常”“我在废土世界种草莓”“青春甜宠”）以及热搜榜列表结构，证明搜索页是一个完整的内容发现页而非单一输入框。
- **截图文件**：`assets/2026-07-24-step-01-search-entry.xml`
