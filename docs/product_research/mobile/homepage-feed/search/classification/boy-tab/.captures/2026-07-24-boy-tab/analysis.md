### 流程步骤分析

#### 步骤 1：进入分类页

- **触发**：从首页进入搜索页后点击“分类”。
- **响应**：进入分类中心，默认停留在“全部”内容池。
- **转场**：整页跳转到分类页。
- **截图引用**：`assets/2026-07-24-step-01-classification-page.png`

#### 步骤 2：切换到“男生”Tab

- **触发**：点击顶部“男生”Tab。
- **响应**：内容池切换为男生向标签体系，顶部高亮变为“男生”，右侧标签矩阵替换为更偏男性向的题材与角色标签，如“逆袭 / 马甲 / 都市日常 / 重生 / 穿越 / 系统 / 战神归来 / 异能 / 玄幻仙侠 / 赘婿逆袭 / 无敌神医 / 悬疑推理 / 神豪 / 强者回归 / 龙王”等。
- **转场**：同页内大类 Tab 切换。
- **截图引用**：`assets/2026-07-24-step-02-boy-tab.png`

#### 步骤 3：返回搜索页

- **触发**：在男生 Tab 状态点击返回。
- **响应**：直接回到搜索承接页，而不是回到分类页“全部”态。
- **转场**：整页返回搜索页。
- **截图引用**：`assets/2026-07-24-step-03-back-context.png`

## 业务逻辑分析

### 加载策略

| 场景 | 加载方式 | 耗时（估算） | 说明 |
|------|---------|-------------|------|
| 分类页切换男生 Tab | 同页切换 | ~2s | 不离开分类页框架，只替换内容池 |
| 男生 Tab 返回搜索页 | 整页返回 | ~2s | 直接退出整个分类承接层 |

### 内容策略

- 男生 Tab 相比“全部”态，标签体系更集中在升级、逆袭、强者回归、系统、异能、神豪、龙王等男性向爽文/成长题材上。 `[推断]`
- 顶部男生/女生 Tab 不是单纯视觉筛选，而是整套内容池切换机制，会整体重组右侧标签矩阵。 `[推断]`
- 返回直接回搜索页，说明内容池切换虽发生在分类页内部，但用户操作上仍被视为搜索体系下的一层独立分类承接页。 `[推断]`

### 状态管理

| 状态场景 | UI 表现 | 用户可操作项 | 截图 |
|---------|--------|-------------|------|
| 男生内容池浏览态 | 顶部“男生”高亮 + 男性向标签矩阵 | 切换维度、点击标签、切换女生/全部 | `assets/2026-07-24-step-02-boy-tab.png` |
| 返回恢复态 | 搜索页状态保留 | 继续搜索、继续点分类/排行等入口 | `assets/2026-07-24-step-03-back-context.png` |

## 关键发现

1. **男生 Tab 是独立内容池切换**：并非只改变一两个标签，而是整块右侧标签体系重组。
2. **男生向题材偏“升级爽感”**：如系统、逆袭、战神归来、强者回归、神豪、龙王等。 `[推断]`
3. **左侧维度结构不变**：变化主要发生在右侧标签内容。
4. **返回直接回搜索页**：男生 Tab 不会单独保留回到“全部”态的中间返回层。
