## 功能概览

theme-plot 是红果分类中心“女生”Tab 下的主题情节标签组，用于在女性向内容池内按叙事主题进一步筛选内容。它不是独立页面，而是女生内容池同页长页中的中段标签分组。

## Use Cases

### UC-1：用户浏览女生 Tab 的主题情节标签组

![女生 Tab 主题情节标签组](.captures/2026-07-24-theme-plot/assets/2026-07-24-step-01-theme-plot.png)
*图：女生 Tab 中段可见的主题情节标签组 | 采集于 2026-07-24*

- **场景**：用户已经切换到女生内容池，希望按更具体的关系、成长或情感叙事主题缩小范围。
- **操作**：进入分类页“女生”Tab，浏览右侧“主题情节”分组。
- **响应**：系统展示女性成长、闪婚、暗恋成真、现代言情、豪门恩怨、现言甜宠等女性向标签，同时保留打脸虐渣、逆袭、重生等通用爽感题材。
- **转场**：同页内浏览分组，无新页面跳转。

### UC-2：用户从女生 Tab 主题情节状态返回搜索页

![返回搜索页](.captures/2026-07-24-theme-plot/assets/2026-07-24-step-02-back-context.png)
*图：从女生 Tab 主题情节状态返回搜索承接页 | 采集于 2026-07-24*

- **场景**：用户浏览完主题情节标签后，想回搜索页继续探索其他入口。
- **操作**：点击返回。
- **响应**：系统直接返回搜索承接页，而不是停留在分类页内部其他分组。
- **转场**：整页返回搜索页。

## 关键发现

- **theme-plot 是女生 Tab 的同页题材分组，而不是独立页面。**
- **题材覆盖宽但重心明确偏女性情感叙事。** `[推断]`
- **平台保留通用爽感题材作为补充**：使女生内容池不只局限于甜宠和关系线。 `[推断]`
- **返回直接退出分类承接层**：该分组没有单独回退层级。
