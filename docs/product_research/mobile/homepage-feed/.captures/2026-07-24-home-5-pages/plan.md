## 操作序列

> 以下步骤在规划阶段填入。采集阶段逐步骤执行，每步完成后回填「观察」和「截图文件」。

### 步骤 1：冷启动并稳定到首页首屏

- **操作**：停止红果后重新启动，等待首页首屏稳定
- **命令**：`adb shell am force-stop com.phoenix.read && adb shell monkey -p com.phoenix.read -c android.intent.category.LAUNCHER 1 && sleep 4`
- **截图**：保存为 `assets/2026-07-24-step-01-home.png`
- **观察要点**：确认默认落点、顶部入口、右侧互动列、底部导航和浮层

*采集阶段回填：*
- **观察**：冷启动后直接进入首页 Feed，首页首屏采用竖屏短剧推荐流。左上角为汉堡菜单，右上角为搜索入口；右侧互动列依次可见金币收益入口、收藏、评论、点赞、分享；底部为“首页/剧场/商城/赚钱/我的”五个一级 Tab，其中“首页”高亮。视频画面在模拟器中仍有彩条/花屏问题，但标题、标签、互动数和底部完整观看入口可正常识别。
- **截图文件**：`assets/2026-07-24-step-01-home.png`

### 步骤 2：首页打开评论面板

- **操作**：在首页点击右侧评论按钮，等待评论抽屉稳定
- **命令**：`adb shell input tap 1005 1545 && sleep 2`
- **截图**：保存为 `assets/2026-07-24-step-02-comments.png`
- **观察要点**：关注评论承接形态、是否半屏、匿名可见内容、底部输入区形态

*采集阶段回填：*
- **观察**：点击评论按钮后，以底部半屏抽屉形式拉起评论面板，标题显示“470条评论”。匿名态下可直接浏览评论内容、点赞数和回复入口，底部输入框提示“有趣评论千千万，不如你也来一条？”，并提供图片/表情入口；未登录也可围观评论，但输入和更深互动预计仍受账号约束。顶部视频区域仍保留在背景中，说明评论采用覆盖式抽屉而非整页跳转。
- **截图文件**：`assets/2026-07-24-step-02-comments.png`

### 步骤 3：从首页打开搜索页

- **操作**：返回首页后点击右上搜索按钮，等待搜索页稳定
- **命令**：`adb shell input tap 1000 110 && sleep 2`
- **截图**：保存为 `assets/2026-07-24-step-03-search.png`
- **观察要点**：关注搜索页结构、热搜/推荐、搜索框、匿名可见模块

*采集阶段回填：*
- **观察**：搜索入口进入独立搜索页。顶部为返回按钮、搜索框与“搜索”按钮，下方提供“识剧 / 排行 / 上新 / 演员 / 分类”快捷入口；中部展示搜索历史与“猜你想搜”，底部是热搜榜内容。当前搜索框保留上次检索词，且页面出现系统悬浮工具提示与截图搜索浮层，说明搜索页既保留历史状态，也会叠加系统辅助入口。匿名态下可直接浏览搜索历史、推荐卡片和热搜榜。
- **截图文件**：`assets/2026-07-24-step-03-search.png`

### 步骤 4：从首页打开左侧菜单抽屉

- **操作**：返回首页后点击左上菜单按钮，等待抽屉展开
- **命令**：`adb shell input tap 72 116 && sleep 2`
- **截图**：保存为 `assets/2026-07-24-step-04-menu.png`
- **观察要点**：关注登录 CTA、抽屉信息架构、个人中心能力聚合情况

*采集阶段回填：*
- **观察**：点击左上菜单后，从左侧滑出个人中心式抽屉。顶部展示“登录看完整信息 / 立即登录”CTA，中部包含“最近在看”续播卡片，下方有“游戏中心”和“常用功能”，常用功能中可见“我的预约”“我的下载”。右侧保留暗化后的首页背景，说明该入口是侧滑抽屉，不是独立整页导航。
- **截图文件**：`assets/2026-07-24-step-04-menu.png`

### 步骤 5：首页进入完整观看承接页

- **操作**：关闭抽屉回首页后，点击底部“观看完整短剧/漫剧”入口，等待播放承接页稳定
- **命令**：`adb shell input tap 540 2140 && sleep 3`
- **截图**：保存为 `assets/2026-07-24-step-05-full-watch.png`
- **观察要点**：关注承接页是否直接进入播放器、顶部返回/集数/更多操作、与首页的连续性

*采集阶段回填：*
- **观察**：点击底部完整观看入口后，直接进入剧集播放承接页，而非先进入详情页。顶部左侧出现返回按钮并显示当前集数（样本中已到“第3集”），右上可见“倍速”和更多操作；底部固定“选集·已完结·全133集”抽屉栏，右下角还有全屏/更多操作按钮。页面整体保留与首页相似的竖屏播放器语境，但进入了可持续追更的剧集上下文。
- **截图文件**：`assets/2026-07-24-step-05-full-watch.png`
