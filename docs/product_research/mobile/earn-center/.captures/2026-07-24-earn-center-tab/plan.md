# 采集计划 — earn-center

- **采集日期**：2026-07-24
- **采集目标**：采集红果底部“赚钱”Tab 首屏，确认其任务结构、金币收益模块与代表性可下钻入口。
- **入口路径**：`earn-center/`
- **采集环境**：mobile / 红果 7.2.4.32 / Android 匿名态

## 操作步骤

- [x] 步骤 1：冷启动进入首页，切换到“赚钱”Tab，记录首屏页面。
  - 观察：成功进入“赚钱”Tab，顶部以橙色收益头图展示“登录后可领取收益”和现金收益数字，下方依次可见“新人7天 必得6元”“连续看短剧福利”“新人看剧5分钟得1.56元”“现金打款0.5元，微信到账”等任务卡与多个“立即领取 / 立即打款”按钮。
- [x] 步骤 2：选择一个代表性任务入口点击，记录目标页。
  - 观察：点击首屏右侧“立即领取”类奖励入口后，没有进入列表或表单页，而是直接跳转到竖屏短剧播放承接页；页面右侧保留收藏、评论、点赞、分享，底部出现“观看完整漫剧·全84集”，说明奖励任务与内容播放链路直连。
- [x] 步骤 3：执行返回，记录返回后的赚钱上下文。
  - 观察：返回后重新落回“赚钱”Tab 首屏；底部“赚钱”保持选中，顶部收益头图与任务卡片重新可见。
