## 操作序列

### 步骤 1：进入剧场首屏

- **操作**：冷启动并切换至剧场页
- **命令**：`adb shell am force-stop com.phoenix.read && adb shell monkey -p com.phoenix.read -c android.intent.category.LAUNCHER 1 && sleep 5 && adb shell input tap 314 2240 && sleep 3`
- **截图**：保存为 `assets/2026-07-23-step-01-theater-ready.png`
- **观察要点**：确认排行榜入口可见

*执行后由 subagent 填写：*
- **观察**：剧场页默认停留在“找剧”频道，顶部搜索框仍保留历史检索词“我在废土世界种草莓”，右侧为“识剧”入口；首屏功能入口含“筛选”“排行榜”“新剧”“预约”。首屏双列样本卡片为《贬值十亿倍，我登顶世界之巅》《穿越成废材皇子，我坐拥雄兵百万》《十灵根短命？我手搓废丹成仙》《暖心快递员》，说明排行榜入口在剧场首页首屏即可匿名触达。
- **截图文件**：`assets/2026-07-23-step-01-theater-ready.png`

### 步骤 2：打开排行榜

- **操作**：点击“排行榜”入口
- **命令**：`adb shell input tap 420 334 && sleep 3`
- **截图**：保存为 `assets/2026-07-23-step-02-ranking-page.png`
- **观察要点**：记录榜单页结构、榜单分类、默认排序方式

*执行后由 subagent 填写：*
- **观察**：点击后进入独立榜单页，顶部标题为“红果推荐榜”，并显示说明“7月23日已更新·基于红果观看/互动以及个人兴趣排序”。一级分类含“全部、真人剧、漫剧、AI剧、演员”，二级榜单标签含“推荐榜、热播榜、臻果榜、预约榜、新剧榜”，右侧还有“分类”入口。默认落在“全部”+“推荐榜”，榜单以纵向列表展示，首屏前几名包括《从黄鳝到祖龙：吞噬进化》《我觉醒了返利人生》《不争家产，我自拥千万》《渐染》，并显示推荐值、热度、点赞等指标。
- **截图文件**：`assets/2026-07-23-step-02-ranking-page.png`

### 步骤 3：点击榜单首项进入承接页

- **操作**：点击榜单首项或首个榜单标签
- **命令**：`adb shell input tap 260 760 && sleep 3`
- **截图**：保存为 `assets/2026-07-23-step-03-ranking-detail.png`
- **观察要点**：进入详情页/剧集页/榜单分组页中的哪一种，是否属于三级页内

*执行后由 subagent 填写：*
- **观察**：点击推荐榜首项后，没有进入传统图文详情页，而是直接进入全屏播放承接页。当前停留在《从黄鳝到祖龙：吞噬进化》第9集，顶部可见返回、倍速与更多操作，底部有“从第1集开始看”提示以及“选集·已完结·全60集”抽屉栏，右侧仍保留点赞、评论、分享互动列。视频内容区域继续出现大面积花屏/彩条，但剧名、集数与交互结构可识别，说明榜单点击会直接落到播放链路。
- **截图文件**：`assets/2026-07-23-step-03-ranking-detail.png`

### 步骤 4：返回剧场首屏

- **操作**：连续返回到剧场首屏
- **命令**：`adb shell input keyevent KEYCODE_BACK && sleep 1 && adb shell input keyevent KEYCODE_BACK && sleep 2`
- **截图**：保存为 `assets/2026-07-23-step-04-back-theater.png`
- **观察要点**：返回层级、榜单页是否保留滚动状态

*执行后由 subagent 填写：*
- **观察**：第一次返回先退出播放页，第二次返回回到剧场“找剧”主列表，而不是回到排行榜页，因此该路径的返回链路表现为“播放页 → 剧场首页”。回到首页后仍可见“筛选/排行榜/新剧/预约”入口以及双列剧集列表，当前首屏样本恢复为《贬值十亿倍，我登顶世界之巅》《穿越成废材皇子，我坐拥雄兵百万》《十灵根短命？我手搓废丹成仙》《暖心快递员》。
- **截图文件**：`assets/2026-07-23-step-04-back-theater.png`
