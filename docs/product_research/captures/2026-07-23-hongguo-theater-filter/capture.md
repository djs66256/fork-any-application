## 操作序列

### 步骤 1：进入剧场首屏

- **操作**：冷启动后切换到底部剧场 Tab
- **命令**：`adb shell am force-stop com.phoenix.read && adb shell monkey -p com.phoenix.read -c android.intent.category.LAUNCHER 1 && sleep 5 && adb shell input tap 314 2240 && sleep 3`
- **截图**：保存为 `assets/2026-07-23-step-01-theater-ready.png`
- **观察要点**：确认剧场首屏已稳定，“筛选”入口可见

*执行后由 subagent 填写：*
- **观察**：剧场页默认停留在“找剧”频道，顶部搜索框仍残留上轮搜索词“我在废土世界种草莓”，右侧为“识剧”入口；首屏功能入口包含“筛选”“排行榜”“新剧”“预约”。首屏双列卡片可匿名浏览，当前可见样本包括《穿成后我靠系统逆袭（十一）》《暖心快递员》《我在剑宗当团宠，剑宗团宠小师妹》《大明王朝，我为大明续运三百年》。
- **截图文件**：`assets/2026-07-23-step-01-theater-ready.png`

### 步骤 2：打开筛选面板

- **操作**：点击剧场页“筛选”按钮
- **命令**：`adb shell input tap 146 334 && sleep 2`
- **截图**：保存为 `assets/2026-07-23-step-02-filter-panel.png`
- **观察要点**：筛选以弹层/页形式出现，包含哪些维度

*执行后由 subagent 填写：*
- **观察**：点击后进入独立的全页“筛选”页，而不是底部抽屉。筛选维度按左列分组展示，首屏可见“全部体裁、全部主题、全部设定、全部背景、全部推荐、全部受众”；点击“展开”后还会增加“全部时间”。右侧可选项覆盖体裁（短剧、漫剧、AI短剧）、主题（现言、女性成长、脑洞、奇幻、玄幻、古言等）、设定（打脸虐渣、大男主、大女主、马甲、重生等）、背景（现代、都市、古代、乡村、年代、架空等）、推荐（最新上架、最高热度、最高收藏）与受众（男频、女频）。
- **截图文件**：`assets/2026-07-23-step-02-filter-panel.png`

### 步骤 3：应用首个匿名可用筛选条件

- **操作**：点击一个可见筛选项并确认/应用
- **命令**：`adb shell input tap 490 905 && sleep 2`
- **截图**：保存为 `assets/2026-07-23-step-03-filter-result.png`
- **观察要点**：结果列表是否刷新、筛选条件是否回显、是否进入二级结果页

*执行后由 subagent 填写：*
- **观察**：本次没有单独的“确认/应用”按钮，点击筛选项后即刻在同页生效并刷新结果。实际命中的为“全部时间”分组下的“7天内上新”，筛选页顶部仍保留“筛选”标题，底部结果列表同步刷新，首屏样本切换为《从黄鳝到祖龙：吞噬进化》《渐染》《重生八零，改嫁傻夫成团宠》《侦探小姐，警长先生》等，说明筛选采用即时生效模式，而非先选后提交。
- **截图文件**：`assets/2026-07-23-step-03-filter-result.png`

### 步骤 4：返回剧场首屏

- **操作**：返回原剧场页
- **命令**：`adb shell input keyevent KEYCODE_BACK && sleep 2`
- **截图**：保存为 `assets/2026-07-23-step-04-back-theater.png`
- **观察要点**：返回层级、筛选状态保留与否

*执行后由 subagent 填写：*
- **观察**：返回后回到剧场“找剧”首屏列表，不再停留在筛选页；剧场顶部仍保留搜索框与“识剧”入口，功能入口恢复为“筛选/排行榜/新剧/预约”。结果列表停留在已筛选后的样本集首屏，可见《穿成后我靠系统逆袭（十一）》《暖心快递员》《我在剑宗当团宠，剑宗团宠小师妹》《大明王朝，我为大明续运三百年》，说明返回后并未显式回显筛选标签，且列表回到了剧场主列表状态。
- **截图文件**：`assets/2026-07-23-step-04-back-theater.png`

## 异常记录

- 原预置命令中的筛选应用动作 `adb shell input tap 220 640 && adb shell input tap 890 2110` 与实际页面结构不匹配；重跑后改为直接点击“7天内上新”项，确认剧场筛选没有单独确认按钮，而是即时生效。
- `uiautomator dump` 在筛选页与即时生效后的结果页未稳定导出文本节点，关键判断主要依据截图进行。
