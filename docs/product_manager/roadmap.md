## 产品阶段性目标

**当前阶段**：MVP 核心播放体验 → 用户增长 → 商业化

| 阶段 | Sprint | 目标 | 关键 PRD |
|------|--------|------|---------|
| Phase 1 | Sprint 1 | 核心内容消费闭环 | 底部导航、首页 Feed、播放器 |
| Phase 1 | Sprint 2 | 内容发现体系 | 搜索、排行、分类 |
| Phase 1 | Sprint 3 | 个人面板 | 菜单面板 |
| Phase 2 | Sprint 4 | 用户增长与互动 | 登录、评论、签到/消息、资产管理 |
| Phase 3 | Sprint 5 | 内容分发与商业化 | 剧场频道、商城、赚钱中心 |

```

        搜索/排行/分类             AI推荐
```

```
Sprint 3-4 ──→ 中期 ──→ 远期
菜单面板     个人主页  社交互动
登录/注册    收藏历史  社区
评论/消息
```

```
Sprint 5 ──→ 中期 ──→ 远期

赚钱中心    付费内容 直播带货
```
