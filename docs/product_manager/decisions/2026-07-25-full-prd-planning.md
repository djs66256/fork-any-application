### 各方向详解

#### PRD-01：底部导航与应用路由

- **用户价值**：所有频道的基础导航骨架，用户需要在 5 个 Tab 间切换
- **竞品差距**：红果有完整的底部 5 Tab 导航 + 页面路由；我们仅有占位页面
- **实现可行**：iOS SwiftUI TabView、Android Compose NavigationBar、各端路由框架已有 Deeplink 骨架
- **产品战略**：所有后续频道 PRD 的前置依赖

#### PRD-02：首页 Feed 流

- **用户价值**：核心内容消费入口，冷启动默认页面
- **竞品差距**：红果首页为沉浸式竖屏 Feed，含右侧交互栏、底部 CTA
- **实现可行**：需要 Backend 内容 API + iOS/Android 竖屏视频列表播放
- **产品战略**：Phase 1 核心体验，P0 优先级

#### PRD-03：完整观看播放器

- **用户价值**：短剧核心体验 — 从 Feed 进入完整剧集播放
- **竞品差距**：红果有完整播放器（集数、倍速、选集、互动）
- **实现可行**：基于现有播放器 API 扩展（已有 `/api/player/start`、`/api/player/stop`）
- **产品战略**：Phase 1 核心体验，P0 优先级

#### PRD-04~06：搜索发现 + 排行 + 分类

- **用户价值**：补充首页 Feed 之外的内容发现路径
- **竞品差距**：红果有完整的三层发现体系（搜索→排行+分类→列表+筛选）
- **实现可行**：三者共享标签/分类数据模型，后端可统一建设
- **产品战略**：Phase 1 Sprint 2，P1 优先级

#### PRD-07~11：菜单面板 + 登录 + 评论 + 签到 + 资产管理

- **用户价值**：个人资产、社交互动、留存激励
- **竞品差距**：红果菜单面板集成了登录、消息、最近在看、游戏中心、常用功能
- **实现可行**：需要用户体系（Supabase Auth），登录为公共基础能力
- **产品战略**：Phase 2 用户增长，P1 优先级

#### PRD-12~14：剧场频道 + 商城 + 赚钱中心

- **用户价值**：多维度内容发现、电商变现、留存激励
- **竞品差距**：红果三个频道各有完整交互
- **实现可行**：依赖前两阶段基础能力，复杂度较高
- **产品战略**：Phase 3 内容分发与商业化，P1/P2 优先级

## 建议

### 敏捷迭代排序

```
Phase 1: 核心播放与内容消费 (Sprint 1-3)
  Sprint 1: PRD-01(路由) → PRD-02(Feed) → PRD-03(播放器)
  Sprint 2: PRD-04(搜索) → PRD-05(排行) + PRD-06(分类)（可并行）
  Sprint 3: PRD-07(菜单面板)

Phase 2: 用户增长与互动 (Sprint 4)
  Sprint 4: PRD-08(登录) → PRD-09(评论) + PRD-10(签到/消息) + PRD-11(资产管理)（可并行）

Phase 3: 内容分发与商业化 (Sprint 5)
  Sprint 5: PRD-12(剧场) → PRD-13(商城) + PRD-14(赚钱)（可并行）
```

### 优先级排序

1. **P0（Phase 1 Sprint 1）**：PRD-01 底部导航、PRD-02 首页 Feed、PRD-03 播放器 — 核心内容消费闭环
2. **P0（Phase 1 Sprint 2-3）**：PRD-04~07 内容发现 + 菜单面板 — 完整用户体验
3. **P1（Phase 2）**：PRD-08~11 用户体系 — 用户留存与增长
4. **P1（Phase 3）**：PRD-12~14 剧场 + 商城 + 赚钱 — 商业变现
