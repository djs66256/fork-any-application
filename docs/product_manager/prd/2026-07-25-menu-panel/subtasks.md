## 子任务详情

### ST-01：Backend 最近在看 API

- **平台**：Backend | **优先级**：P0 | **工时**：1.5 人日
- `GET /api/user/recently-viewed`：返回最近 3 条播放历史（dramaId + episodeNumber + progress + coverUrl + title）

### ST-02：iOS 抽屉 UI

- **平台**：iOS | **优先级**：P0 | **工时**：2.5 人日
- 实现左侧滑出抽屉（`ZStack` + `offset` 动画），含各模块：登录引导区、最近在看横向卡片、常用功能列表入口

### ST-03：Android 抽屉 UI

- **平台**：Android | **优先级**：P0 | **工时**：2.5 人日
- 同 ST-02，Android 实现（`ModalDrawerSheet` 或自定义 `AnimatedVisibility`）

### ST-04：iOS 首页汉堡菜单入口

- **平台**：iOS | **工时**：1.5 人日
- 首页顶部栏左侧添加汉堡菜单图标 → 点击打开抽屉

### ST-05：Android 首页汉堡菜单入口

- **平台**：Android | **工时**：1.5 人日
