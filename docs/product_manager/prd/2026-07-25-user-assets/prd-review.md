## 🔴 阻塞项

### B-01：Backlog 工时与 PRD 工时严重不一致

- **问题**：`backlog.md` B-016 预估 8 人日，`subtasks.md` 合计仅 4 人日，差距 50%。
- **原因**：backlog B-016 的 scope 包含「我的预约、我的下载、最近在看续播、游戏中心」，但 PRD 实际 scope 仅为「我的预约 + 我的下载入口」。最近在看续播已划入 PRD-07（菜单面板），游戏中心标记为远期迭代。
- **修正**：将 `backlog.md` B-016 的工时更新为 4 人日，并将简述改为「我的预约、我的下载入口」，删除已归属其他 PRD 的功能描述。

### B-02：「我的下载」入口无对应用户故事和验收标准

- **问题**：PRD 1.3 范围定义明确包含「我的下载入口（占位）」，但第 3 节用户故事中没有 US 覆盖该项。既无验收标准，subtasks 中也没有对应的 UI 任务。
- **修正**：新增一条用户故事，例如 `US-03 所有用户：查看下载入口。点击「我的下载」跳转占位页或 Toast 提示。优先级 P1。` 同时在 subtasks 的 iOS/Android 任务中补充下载入口的 UI 实现。

### B-03：Android 子任务描述为空

- **问题**：ST-03（Android 我的预约页）只有工时 1.5 人日，没有任何任务描述。ST-02（iOS）至少列出了组件清单（Tab + 列表 + 空态 + 编辑按钮）。Android 端开发无法据此执行。
- **修正**：参照 ST-02 补充 ST-03 的具体任务描述，至少包含：Tab 切换（已上线/即将上线）、列表（封面+标题+状态）、空态展示、编辑按钮、我的下载入口占位。

### B-04：后端 API 规格缺失

- **问题**：ST-01 仅给出 `GET /api/user/bookings` 路由，缺乏以下关键信息：
  - 请求参数（分页 offset/limit？状态过滤参数？）
  - 响应字段（封面图 URL、标题、状态、预约时间、剧集 ID 等）
  - 错误码定义（未登录 401、空列表 200）
  - 是否需要返回各 Tab 的 count（如竞品所示 `已上线:N`）
- **修正**：补充 API 规格到 subtasks 或 PRD 中，至少定义请求/响应示例。

### B-05：依赖状态标记与实际不符

- **问题**：PRD 第 5 节将所有内部依赖状态标记为 `🚧`（构建中），但 `progress.md` 明确显示 PRD-05（排行预约）、PRD-07（菜单面板）状态均为「规划中 (planned)」，并非构建中。
- **修正**：将 PRD-05 和 PRD-07 的依赖状态改为 `📅`，仅当对应 PRD 进入构建阶段后再更新为 `🚧`。

## 🟡 建议项

### S-01：缺少「编辑/取消预约」的交互细节

- **问题**：US-02 仅简述「右上角编辑按钮，可取消预约」，竞品文档也仅标注为 `[推断]`。未说明编辑模式下的具体交互：是批量多选+删除？左滑删除？点击进入编辑态后复选？取消是否需要二次确认弹窗？
- **建议**：参考竞品文档的截图，补充编辑态的 UI 规格和交互流程。至少给出一个明确的交互方案。

### S-02：预约列表数据字段未定义

- **问题**：PRD 和 subtasks 均未定义预约列表项包含哪些字段。UI 开发需要知道：封面图 URL、短剧标题、预约时间、当前状态（已上线/即将上线）、剧集总数等。
- **建议**：在 PRD 中新增一个小节或在 subtasks ST-01 中补充 response schema。

### S-03：Tab 标签命名与竞品不一致

- **问题**：竞品文档（my-bookings.md）的 Tab 标签为「已上线」和「待上线」，PRD US-01 写的是「已上线」和「即将上线」。
- **建议**：确认使用哪个命名。如无特殊理由，建议与竞品保持一致（「已上线」「待上线」），减少后续理解成本。

### S-04：缺少列表通用交互说明

- **问题**：未提及下拉刷新、上拉加载更多（分页）、列表项点击行为（是否跳转剧集详情页/播放页）。
- **建议**：补充列表交互：下拉刷新触发 API 重新请求；上拉加载分页数据；点击列表项跳转 `/play/:dramaId`。

### S-05：缺少错误/异常状态处理

- **问题**：未定义 API 失败（网络错误、服务端 500）、登录态过期（Token 失效时 401）、空列表等异常场景的 UI 表现。
- **建议**：补充异常状态表。例如：网络错误 → Toast 提示+重试按钮；Token 失效 → 跳转登录页；空列表 → 空态插画+文案。

### S-06：竞品文档中「新剧预约」导航未体现

- **问题**：竞品文档显示我的预约页顶部导航为「返回 + `新剧预约 | 我的预约` + `编辑`」，其中「新剧预约」是一个页面内的子导航/标签。PRD 中只提到了 Tab（已上线/即将上线），但未提及「新剧预约」这个页面标题栏的左侧文字。
- **建议**：确认是否需要此二级标题。如不需要，在 PRD 中注明与竞品的差异及原因。
