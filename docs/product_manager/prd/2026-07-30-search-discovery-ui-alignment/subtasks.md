## 子任务详情

### ST-01：Backend 搜索发现展示字段梳理
- 平台：Backend
- 工时：1 人日
- 内容：补齐排行标题、标签文案、分类展示字段的最小支撑，不改主 contract。

### ST-02：iOS 搜索页 UI 对齐
- 平台：iOS
- 工时：1.5 人日
- 前置依赖：ST-01
- 内容：对齐搜索栏、快捷入口、历史、热搜和结果区视觉结构。

### ST-03：iOS 排行页 UI 对齐
- 平台：iOS
- 工时：1.5 人日
- 前置依赖：ST-02
- 内容：对齐双层筛选结构、标题区和榜单卡片。

### ST-04：iOS 分类页 UI 对齐
- 平台：iOS
- 工时：1.5 人日
- 前置依赖：ST-03
- 内容：对齐顶部人群 Tab、左侧导航和右侧标签矩阵。

### ST-05：Android 搜索页 UI 对齐
- 平台：Android
- 工时：1.5 人日
- 前置依赖：ST-01
- 内容：对齐搜索栏、快捷入口、历史、热搜和结果区视觉结构。

### ST-06：Android 排行页 UI 对齐
- 平台：Android
- 工时：1.5 人日
- 前置依赖：ST-05
- 内容：对齐双层筛选结构、标题区和榜单卡片。

### ST-07：Android 分类页 UI 对齐
- 平台：Android
- 工时：1.5 人日
- 前置依赖：ST-06
