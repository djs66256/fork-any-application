## 🔴 阻塞问题

### B-01：匿名用户签到降级方案不明确

**状态**：✅ 已修正

**位置**：PRD §1.3 范围定义（"未登录降级"）+ ST-01（"本地存储签到日期（未登录降级）"）

**问题**：PRD 和 subtasks 提到未登录时可本地存储签到日期，但未说明后端如何识别匿名用户。

**修正内容**：
1. 在 PRD §4 新增 4.1.x「匿名签到降级方案」：前端检查本地标记 → 调用 API（携带设备 ID）→ 后端记录设备 ID 的签到日期 → 返回 7 日状态
2. 数据存储：客户端 `SharedPreferences/UserDefaults` + 服务端 `device_id` 字段
3. 签到奖励表现：首版为纯 UI 高亮格子（无实际金币），远期接入 PRD-14 赚钱中心
4. 在 subtasks.md ST-01 中补充 `device_id` 参数支持

---

### B-02：签到弹窗触发规则不完整

**状态**：✅ 已修正

**位置**：PRD §3 US-01、§4.1 流程图

**问题**：US-01 验收标准为"每日首次打开 App 弹出 7 日签到弹窗"，但缺失边界条件。

**修正内容**：
1. 在 §4.1 流程图中增加"用户关闭弹窗（未签到）→ 当日不再弹出"分支
2. 在 §4.1 补充触发策略说明：每日首次冷启动必弹、关闭后当日不再弹出、后台回前台不触发
3. 说明了与竞品"偶发弹出"不同的设计理由：首版无金币体系，不需要控制弹出频率以管理成本
