## 子任务详情

### ST-01：Backend 签到 API

- 工时：1.5 人日 | P0
- `POST /api/signin/checkin`（当日签到，支持 `device_id` 参数供匿名用户使用）、`GET /api/signin/status`（7 日签到状态，支持 `device_id` 参数供匿名用户使用）、本地存储签到日期（未登录降级）

### ST-02：Backend 消息 API

- 工时：1.5 人日 | P0
- `GET /api/messages`（消息列表，分系统消息+互动消息，分页参数 `?page=1&pageSize=20`，按 `createdAt` 倒序，支持下拉刷新和上拉加载更多）
- `GET /api/messages/unread-count`（返回 `{ "count": number }` 供 PRD-07 菜单面板展示未读标记）
- 种子数据：2-3 条系统通知，如"欢迎使用 ShortDrama"、"新剧上线通知"（占位数据，后续由运营后台替换）

### ST-03：iOS 签到弹窗 + 消息页

- 工时：1.5 人日 | P0
- 签到弹窗 overlay 实现、冷启动触发逻辑、消息页（系统通知列表+互动消息登录提示）

### ST-04：Android 签到弹窗 + 消息页

- 工时：1.5 人日 | P0
- 签到弹窗 overlay 实现、冷启动触发逻辑、消息页（系统通知列表+互动消息登录提示）

### ST-05：iOS 菜单面板消息入口集成

- 工时：1 人日 | P1

### ST-06：Android 菜单面板消息入口集成

- 工时：1 人日 | P1
