## 子任务详情

### ST-01：Backend 首页展示字段梳理

| 属性 | 值 |
|------|-----|
| **对应 PRD** | US-01, US-03 |
| **平台** | Backend |
| **优先级** | P1 |
| **预估工时** | 1 人日 |
| **前置依赖** | 无 |

#### 工作内容

1. 盘点首页 UI 对齐所需的标题、标签、热度、文案字段。
2. 仅在首屏展示被现有字段阻塞时补充最小 mock/seed 支撑。
3. 不调整首页主接口 contract。
