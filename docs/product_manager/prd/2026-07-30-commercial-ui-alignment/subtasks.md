## 子任务详情

### ST-01：Backend 商业化页面展示字段梳理
- 平台：Backend
- 工时：0.5 人日
- 内容：补齐商城和赚钱中心首屏所需的最小展示字段与占位文案，不改主 contract。

### ST-02：Web mall / earn H5 首屏 UI 对齐
- 平台：Web
- 工时：1.5 人日
- 前置依赖：ST-01
- 内容：对齐 `/mall`、`/earn` 的顶部区、运营区、列表区、空态与错误态首屏视觉。

### ST-03：iOS H5 宿主容器 UI 对齐
- 平台：iOS
- 工时：1.5 人日
- 前置依赖：ST-02
- 内容：对齐商城和赚钱中心宿主标题区、容器边界、加载态、登录拦截与返回过渡样式。

### ST-04：Android H5 宿主容器 UI 对齐
- 平台：Android
- 工时：1.5 人日
- 前置依赖：ST-02
- 内容：对齐商城和赚钱中心宿主标题区、容器边界、加载态、登录拦截与返回过渡样式。
