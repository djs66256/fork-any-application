## 子任务详情

### ST-01：Backend 个人域展示字段梳理
- 平台：Backend
- 工时：0.5 人日
- 内容：补齐菜单、消息、预约页所需的最小展示字段和占位文案，不改主 contract。

### ST-02：iOS 菜单抽屉与预览区 UI 对齐
- 平台：iOS
- 工时：2 人日
- 前置依赖：ST-01
- 内容：对齐登录区、消息预览、最近在看、常用功能区和抽屉整体层级。

### ST-03：iOS 签到/消息/资产页 UI 对齐
- 平台：iOS
- 工时：1.5 人日
- 前置依赖：ST-02
- 内容：对齐签到弹窗、消息页、我的预约/下载页及相关状态样式。

### ST-04：Android 菜单抽屉与预览区 UI 对齐
- 平台：Android
- 工时：2 人日
- 前置依赖：ST-01
- 内容：对齐登录区、消息预览、最近在看、常用功能区和抽屉整体层级。

### ST-05：Android 签到/消息/资产页 UI 对齐
- 平台：Android
- 工时：1.5 人日
- 前置依赖：ST-04
- 内容：对齐签到弹窗、消息页、我的预约/下载页及相关状态样式。
