## 一、测试范围

### 1.1 测试目标

本次针对 PRD-11“个人资产管理”输出黑盒 QA 用例设计，覆盖 Backend、iOS、Android 的核心用户路径与后端契约关注点，重点验证以下内容：

- 菜单进入“我的预约”的正向路径
- 匿名用户登录承接与登录后回 booking route
- “已上线 / 待上线”双 Tab 切换与 `summary` 一致性
- 空态、错误态、401 回登录承接态
- 分页追加失败时不清空已有列表
- Backend `GET /api/users/me/bookings` 的黑盒契约关注点：
  - query/default
  - 空列表
  - 超大页码
  - 状态映射
  - 脏数据过滤
- “我的下载”继续占位
- Web skipped 边界

说明：

- 本次仅完成 QA 用例设计。
- 当前仓库会话中未发现可用于真机/模拟器执行的 device-testing 类 skill，因此**无法开展设备/模拟器黑盒执行**。
- 执行结果区据实标记为“⏭️ 跳过”或“⚠️ 阻塞”，不伪造真实执行结论。
