## 一、测试范围

### 1.1 测试目标

验证 PRD-13 商城在 Backend、Web、iOS、Android 四端的黑盒行为是否满足需求与设计约束，重点覆盖以下能力：

- 底部 `mall` 一级频道从占位页切换为真实商城承接
- Native 容器加载商城 H5 首页并维持 `mall` tab 高亮
- 商城首页固定区块：搜索入口、购物车入口、5 个快捷入口、活动横幅、双列商品 Feed
- `GET /api/mall/products` 首屏加载、分页追加、空态与错误态契约
- 匿名商品点击触发 H5 页内登录拦截、Native 登录承接与返回恢复
- 已登录商品点击进入 H5 商品详情占位页
- 搜索 bridge、登录态同步、上下文恢复与浏览器 fallback

### 1.2 涉及平台

| 平台 | 是否涉及 | 说明 |
|------|---------|------|
| Backend | ✅ | 新增 `GET /api/mall/products`，负责商品 Feed 分页、空态与统一错误结构 |
| iOS | ✅ | `mall` tab 接入 `WKWebView` 容器、搜索/登录 bridge、返回恢复 |
| Android | ✅ | `mall` graph 接入 `WebView` 容器、搜索/登录 bridge、返回恢复 |
| Web | ✅ | 提供 `/mall` H5 首页与 `/mall/product/[id]` 商品详情占位页 |

### 1.3 不测试的内容

| 内容 | 不纳入原因 |
|------|-----------|
| 真实购物车、订单、钱包、券包、国补专区业务 | 本期仅要求入口反馈“功能开发中”，不交付真实业务页 |
| 商品详情真实交易链路（SKU、库存、加购、下单、支付） | 本期只交付商品详情占位页 |
| banner 后台动态运营配置 | 首版为 Web 侧集中 seed/config，不涉及后台配置平台 |
| Native 侧独立商品详情页 | 明确不做，详情继续由 H5 承载 |
| 设备/模拟器上的真实黑盒执行 | 当前仓库未提供设备/模拟器 testing skill，本会话仅产出测试文档并按 workflow 规则跳过执行 |
