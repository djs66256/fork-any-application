## 一、测试范围

### 1.1 测试目标

验证各端工程骨架是否满足 spec 中定义的可独立构建运行、统一规范等成功指标。聚焦工程层面的构建、测试、lint 和基础设施验证，不涉及业务功能 UI 交互。

### 1.2 涉及平台

| 平台 | 是否涉及 | 说明 |
|------|---------|------|
| Backend | ✅ | Next.js 16 + TypeScript，验证 build/lint/test |
| iOS | ✅ | Swift 6 + SwiftUI + XcodeGen，验证 xcodegen + build + test |
| Android | ✅ | Kotlin 2.0 + Jetpack Compose，验证 assembleDebug + test + detekt |
| Web | ✅ | Next.js 16 + React 19，验证 build/lint/test |

### 1.3 不测试的内容

| 不测试内容 | 原因 |
|-----------|------|
| 设备/模拟器 UI 交互 | 设备测试 skill 未定义 |
| 业务功能（首页 Feed、播放器等） | 属于后续 PRD |
| 用户认证流程 | 属于后续 PRD，当前仅骨架 |
| 数据库实际读写 | 本地环境依赖 Docker，CI 环境不可用 |
| 跨端 Deep Link 实际唤起 | 需真机/模拟器环境 |
