### 问题 3：Health API 响应字段命名不一致

- **严重程度**：🟢 低
- **维度**：一致性
- **描述**：Section 5.2 的 flow 图中使用 `db: connected`（第 159 行），但正式 UI 描述（第 182 行）和完整 JSON 示例中使用 `database: connected`。字段名不统一会导致前后端对接时产生歧义。
- **修复状态**：❌ 未修复
- **修复说明**：将流程图中 `db:` 统一改为 `database:`，与正式 API 响应格式保持一致。或者如果后端实际返回 `db`，则正文和 UI 描述也要相应修改。**建议统一使用 `database`**，语义更清晰。

- **修复状态**：❌ 未修复
