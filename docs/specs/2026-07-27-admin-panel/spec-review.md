## 发现的问题

### 问题 1：`episode_count` 与 `total_episodes` 字段名不一致

- **严重程度**：🔴 高
- **维度**：一致性
- **描述**：spec 6.4 节建议 Supabase 数据库表使用 `episode_count` 列名以匹配 Zod Schema。但现有 migration `00000000000001_init_tables.sql` 中 `dramas` 表已使用 `total_episodes INTEGER NOT NULL DEFAULT 0`。两者冲突。
- **修复状态**：✅ 已修复
- **修复说明**：决策统一为 `episode_count`（以 Zod Schema 为权威来源）。spec 6.4 节和 7 节「迁移策略」中明确了新增 migration 将 `total_episodes` 重命名为 `episode_count`。
