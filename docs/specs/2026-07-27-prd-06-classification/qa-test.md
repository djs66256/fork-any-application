## 一、测试范围

### 1.1 测试目标

验证 PRD-06 分类浏览在 Backend、iOS、Android 三端的黑盒验收范围是否完整覆盖：

- 从搜索发现页点击「分类」进入真实分类页，而不是 placeholder；
- 默认加载 `gender=all`，并展示固定三维度：时代背景 / 主题情节 / 角色设定；
- 性别 Tab 切换后只展示最后一次有效结果，左侧默认维度重置为首项；
- 左侧维度点击与右侧标签分组滚动保持同步；
- 空维度不被隐藏，而是保留分组标题与空态；
- 标签点击后继续复用现有搜索结果页，不新增独立分类结果页；
- Backend `GET /api/dramas/tags` 与搜索 `title + category + tags` 能力满足跨端消费契约。

本次阶段同时记录当前环境限制：**本会话未提供设备/模拟器黑盒操作 skill，因此无法执行真实终端黑盒点击流程；Android 端当前环境也缺少 Java Runtime，无法在本会话补跑 Gradle 校验。按照 feature-workflow 约定，本阶段仅产出 QA 用例文档并跳过设备执行步骤。**

### 1.2 涉及平台

| 平台 | 是否涉及 | 说明 |
|------|---------|------|
| Backend | ✅ | 提供 `GET /api/dramas/tags`，并把搜索扩展到 `title + category + tags` |
| iOS | ✅ | `classificationHome` 已替换为真实分类页 |
| Android | ✅ | `classification` 已替换为真实分类页 |
| Web | ❌ | 本 PRD 不涉及 Web 分类页 |

### 1.3 不测试的内容

- Web 分类页：本 PRD 范围外。
- 真实运营后台配置标签：本 PRD 首版不包含标签管理后台。
- 终端真机/模拟器滚动手势与视觉细节：当前会话没有 device-testing skill。
- Android 本地编译结果：当前环境缺少 Java Runtime，无法执行 Gradle 测试 / 构建 / detekt。
- Supabase 已连接环境中的 migration 应用验证：当前环境未完成 `supabase link`，无法执行 `npx supabase db push` 实际落库验证。
