## 一、测试范围

### 1.1 测试目标

验证 PRD-10 在 Backend、iOS、Android 三端的首版签到与消息系统是否完成主链路交付，包括：首页冷启动签到浮层、签到提交幂等、菜单消息预览、独立消息中心、匿名/登录态互动消息分流，以及路由与登录回流。由于当前会话未提供设备/模拟器黑盒操作 skill，本次阶段以黑盒测试文档产出为主，并结合各端已完成的自动化验证结果补充执行依据。

### 1.2 涉及平台

| 平台 | 是否涉及 | 说明 |
|------|---------|------|
| Backend | ✅ | 已完成 5 个接口、定向测试、build、部分基础设施验证 |
| iOS | ✅ | 已完成数据层、首页签到浮层、菜单消息预览、消息中心、登录回流及测试构建验证 |
| Android | ✅ | 已完成数据层、首页签到浮层、菜单消息预览、消息中心、登录回流及测试构建验证 |
| Web | ❌ | 本需求不涉及 Web 端实现 |

### 1.3 不测试的内容

- 推送通知、消息详情页、后台消息模板配置：不在 PRD-10 范围内。
- Web 用户端消息中心：本需求明确不涉及。
- 真机 / 模拟器交互黑盒执行：当前会话无设备/模拟器测试 skill，无法自动执行。
- Supabase 本地 migration 落库黑盒闭环：backend 侧 `supabase db push --local` 因本地连接问题未完成，仅保留已编写 migration 和仓储测试结果。
