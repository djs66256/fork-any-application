## 一、测试范围

### 1.1 测试目标

验证 PRD-02 首页信息流是否满足以下目标：

- Backend `GET /api/dramas` 已按 canonical contract 提供首页首屏 Feed 数据与分页元信息；
- 首页首屏覆盖首次加载成功、播放入口、详情入口、空态、错误态、重试恢复；
- Backend 分页默认值、第二页、大页码、非法参数、501 占位接口均具备可验证结果；
- iOS / Android 首页在路由语义与状态机定义上保持一致；
- 页面承载边界明确：`mall` / `earn` 继续由 H5 承载，不纳入本期 Native Feed 黑盒执行范围。

本次 QA 阶段同时记录两类证据：

1. **已执行的自动化验证**：Backend 已基于现有自动化测试完成接口契约、分页和占位接口验证；
2. **未执行的设备黑盒步骤**：由于当前会话未提供设备/模拟器测试 skill，iOS / Android 真实页面加载、点击跳转、错误恢复与跨端对照场景仅记录为“跳过”。

### 1.2 涉及平台

| 平台 | 是否涉及 | 说明 |
|------|---------|------|
| Backend | ✅ | 已有自动化测试覆盖首页列表契约、分页参数和 501 占位接口 |
| iOS | ✅ | 需求涉及首页 Feed，但当前未执行设备/模拟器黑盒测试 |
| Android | ✅ | 需求涉及首页 Feed，但当前未执行设备/模拟器黑盒测试 |
| Web | ❌ | 共享方案明确 Web 首页本期不实现 Feed |

### 1.3 不测试的内容

- 不执行 iOS / Android 真机或模拟器黑盒操作，因为当前会话未提供设备/模拟器测试 skill。
- 不验证商城（mall）与赚钱（earn）的 Native Feed 展示，因为 `PRODUCT.md` 与 spec 已明确这两类页面按 H5 容器承载，不属于本期 Native 首页 Feed。
- 不扩展 Web 首页 Feed 测试，因为 spec / design 明确 Web 不在本期实现范围。
- 不验证推荐算法、个性化排序、下拉刷新、自动加载更多，因为本期 MVP 只覆盖首页首屏第一页。
