## 一、测试范围

### 1.1 测试目标

验证 PRD-04 搜索发现需求在 Backend / iOS / Android 三端的黑盒可验收范围是否完整，覆盖以下主链路：

- 首页右上角搜索入口进入 Native 搜索发现页
- 搜索发现页的搜索框、快捷入口、搜索历史、热搜榜
- 手动输入 / 历史词 / 热搜词触发搜索结果页
- 搜索结果页的 loading / content / empty / error 四态
- 结果卡片继续进入既有“观看 / 详情”主链路
- Backend 搜索与热搜接口的功能边界、参数约束与错误处理

> 本轮会话未定义设备 / 模拟器黑盒执行 skill，因此本阶段按 workflow 规范降级为**仅产出 QA 测试文档**；不执行真机 / 模拟器操作，用例执行结果统一暂记为「⏭️ 跳过」。

### 1.2 涉及平台

| 平台 | 是否涉及 | 说明 |
|------|---------|------|
| Backend | ✅ | 新增 `GET /api/dramas/search` 与 `GET /api/dramas/hot-search` |
| iOS | ✅ | 首页搜索入口、搜索发现页、搜索结果页、快捷入口承接页、本地历史 |
| Android | ✅ | 首页搜索入口、搜索发现页、搜索结果页、快捷入口承接页、本地历史 |
| Web | ❌ | 本期不做真实搜索实现，继续保持占位 |

### 1.3 不测试的内容

- Web `/search`、`/rankings` 占位页：不属于本期交付范围。
- `mall` / `earn` H5 页面：与本期搜索发现无关。
- 真实搜索日志聚合热搜：首版允许静态 / 伪实时种子数据。
- PRD-05 排行真实业务页、PRD-06 分类真实业务页：本期仅验证 Native 承接路径，不要求真实业务能力完整落地。
- 真机 / 模拟器点击、截图和设备兼容矩阵：当前会话未定义设备测试 skill，无法执行。
