## 一、测试范围

### 1.1 测试目标

覆盖 PRD-08 在 Backend / iOS / Android 三端定义的登录主链路、协议门禁、会话恢复、refresh、退出登录与排行预约登录拦截回跳能力，形成可执行的黑盒测试清单。

本轮 QA 阶段按 `feature-workflow` 规范降级执行：**当前仓库未定义设备/模拟器测试 skill，因此仅产出测试文档，不执行设备黑盒步骤**。

### 1.2 涉及平台

| 平台 | 是否涉及 | 说明 |
|------|---------|------|
| Backend | ✅ | 提供 OTP、创建 session、refresh、me、logout 认证 API contract |
| iOS | ✅ | 承接“我的”频道登录入口、登录页、设置页、登录拦截回跳 |
| Android | ✅ | 承接“我的”频道登录入口、登录页、设置页、登录拦截回跳 |
| Web | ❌ | 本期不涉及 Web 登录页或 Web 认证闭环 |

### 1.3 不测试的内容

- 生产短信供应商、真实短信送达链路：本期开发与 QA 口径允许使用本地测试 OTP / bypass。
- Web 端登录与注册：本期不在范围内。
- 真机 / 模拟器交互执行：当前无对应 skill，按流程规则跳过设备执行步骤。
- Android 本地 Gradle / JVM 验证：当前环境缺少 Java Runtime，不属于本轮 QA 黑盒执行范围。
